# Welchen emuMMC hab ich?

Es gibt **zwei emuMMC-Typen**. So findest du heraus, welchen du nutzt – am **PC** oder in **Hekate**.

---

## Am PC

>>> emuMMC-Ordner öffnen
Auf der SD-Karte den Ordner **`/emuMMC`** öffnen.

**SD Partition emuMMC:** Unterordner wie `RAW1`, `RAW2`, …

![Partition emuMMC (RAW)|700x420](/images/switch/allgemein/emummc.jpg)

**SD File emuMMC:** Ordner wie `SD00`, `SD01`, …

![File emuMMC (SD00)|700x420](/images/switch/allgemein/emummc2.jpg)

>>>

---

## In Hekate

>>> emuMMC-Menü öffnen
Switch in **Hekate** starten → **Close** → **emuMMC**.

>>> Typ ablesen
Oben links bei **Enable** steht der aktive Typ, z. B.:

- **Type: SD RAW** → Partition-basierter emuMMC
- **SD00**, **SD01**, … → Datei-basierter emuMMC

![emuMMC-Typ in Hekate|700x420](/images/switch/allgemein/emummc3.jpg)

>>>

!!!success Kurzfassung
**RAW1 / SD RAW** = **Partition-emuMMC** · **SD00 / SD01** = **Datei-emuMMC**
!!!
