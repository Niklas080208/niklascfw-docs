# Theme installieren

!!!warning FW 20.x – Theme-Kompatibilität
Nicht alle Themes sind mit **Firmware 20.x** kompatibel (steht meist beim Theme). Bei Fehler **0100000000000001000** nach Reboot: [Custom Theme entfernen](https://docs.niklascfw.de/switch/fehlerbehebung/theme-visual/0100000000000001000_beheben_(custom_theme)/).
!!!

---

## NXThemes Installer (für beide Wege)

>>> NXThemes Installer installieren
**NXThemes Installer** im **Sphaira HB-Store** laden und installieren.

![NXThemes Installer|700x420](/images/switch/gut-zu-wissen/customization/theme-install/nxthemes_install.jpg)

>>> Highmemory-Mode und Home Menu extrahieren
**NXThemes Installer** starten – **zwingend im Highmemory-Mode** (Title Override / Forwarder). Beim ersten Start **Extract home menu** bestätigen.

>>>

---

## Themes über Themezer (PC + Switch)

>>> Theme auf Themezer finden
Am PC [Themezer.net](https://themezer.net/) öffnen und Theme oder Paket auswählen.

![Themezer Code|700x420](/images/switch/gut-zu-wissen/customization/theme-install/themezer_code.jpg)

>>> Code in NXThemes eingeben
In **NXThemes Installer** unter **Download Themes** den Code in **Input text** eintragen und **Search** tippen.

![Theme suchen|700x420](/images/switch/gut-zu-wissen/customization/theme-install/theme1.jpg)

>>> Teile auswählen und laden
Auf der Download-Seite gewünschte Theme-Teile markieren und **Download all** bestätigen.

![Download-Auswahl|700x420](/images/switch/gut-zu-wissen/customization/theme-install/theme2.jpg)

>>> Theme installieren
Links **Themes** → **Downloads**, dein Theme wählen.

![Themes-Liste|700x420](/images/switch/gut-zu-wissen/customization/theme-install/theme3.jpg)

![Theme aus Downloads|700x420](/images/switch/gut-zu-wissen/customization/theme-install/theme4.jpg)

Teile auswählen, die installiert werden sollen, und bestätigen.

![Installation bestätigen|700x420](/images/switch/gut-zu-wissen/customization/theme-install/theme5.jpg)

>>> Neustart
Über **Reboot → Reboot** die Switch neu starten.

![Reboot|700x420](/images/switch/gut-zu-wissen/customization/theme-install/theme6.jpg)

>>>

!!!success Fertig
Nach dem Neustart sollte dein Theme aktiv sein.
!!!
